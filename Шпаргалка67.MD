Git — основные команды
1. Проверка версии Git
Перед началом работы проверяем, установлен ли Git и какая версия используется:
git --version
2. Инициализация репозитория
git init
Инициализирует Git в текущей папке.
После выполнения команды в папке создаётся скрытая директория .git, в которой Git хранит информацию о репозитории и его истории.
git init
3. Проверка состояния
git status
Показывает текущее состояние репозитория:
- какие файлы изменены;
- какие файлы добавлены;
- какие изменения готовы к коммиту;
- какие файлы Git ещё не отслеживает.
git status
Чтобы быстро вызвать ранее введённую команду, используйте ↑ (стрелку вверх).
4. Добавление файлов
git add
Добавляет изменения в индекс (staging area) — область подготовки следующего коммита.
Например:
git add файл.txt
Чтобы добавить все изменённые файлы:
git add .
После git add изменения ещё не сохранены в истории — они только подготовлены к коммиту.
5. Создание коммита
git commit
Фиксирует подготовленные изменения и сохраняет их в истории Git.
Обычно используется с сообщением:
git commit -m "Описание изменений"
Git берёт изменения, добавленные через git add, создаёт их сохранённую версию и добавляет её в историю репозитория.
6. Просмотр истории
git log
Показывает историю коммитов:
- количество сохранений;
- авторов;
- даты;
- сообщения коммитов;
- идентификаторы коммитов.
git log
Для выхода из просмотра журнала нажмите q.
7. Переключение между версиями
git checkout
Позволяет переключаться между версиями файлов или ветками.
Для перехода к определённому коммиту указывается его идентификатор:
git checkout <идентификатор-коммита>
Чтобы вернуться на основную ветку:
git checkout master
Цитата В современных репозиториях основная ветка чаще называется main, поэтому может использоваться:
git checkout main
8. Просмотр изменений
git diff
Показывает разницу между текущими изменениями и сохранённой версией.
git diff
Это позволяет увидеть, какие строки были добавлены, удалены или изменены.
Markdown — основные элементы
Markdown — простой язык разметки текста.
Жирный текст
Используются две звёздочки:
**жирный текст**
Результат: жирный текст
Курсив
Используются одна звёздочка:
*курсив*
Результат: курсив
Зачёркнутый текст
Используются две тильды:
~~зачёркнутый текст~~
Результат: зачёркнутый текст
Заголовки
Перед текстом ставится символ #:
# Заголовок 1
## Заголовок 2
### Заголовок 3
Количество # определяет уровень заголовка.
Нумерованный список
Используются обычные цифры:
1. Первый пункт
2. Второй пункт
3. Третий пункт
Ненумерованный список
Используются *, - или +:
* Первый пункт
* Второй пункт
* Третий пункт
Вложенный список
Для создания вложенности используется отступ:
* Первый пункт
  * Вложенный пункт
  * Ещё один вложенный пункт
* Второй пункт
