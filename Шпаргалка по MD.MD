# GIT — ОСНОВНЫЕ КОМАНДЫ

## Проверка версии Git

Перед началом работы проверяем, установлен ли Git и какая версия используется.

`git --version`

<img width="507" height="60" alt="image" src="https://github.com/user-attachments/assets/bf03c1a1-5089-49ba-a736-408cca0a7894" />

## Инициализация репозитория

`git init`

<img width="668" height="73" alt="image" src="https://github.com/user-attachments/assets/931aa352-80a6-4904-ad50-ad591f65d91d" />

Инициализирует Git в текущей папке.

После выполнения команды в папке создаётся скрытая папка `.git`, в которой Git хранит информацию о репозитории и его истории.

## Проверка состояния

`git status`

<img width="620" height="201" alt="image" src="https://github.com/user-attachments/assets/ff9bbc19-36c0-49be-a5e8-6adda4b3b182" />

Показывает текущее состояние репозитория:

*   какие файлы изменены;
*   какие файлы добавлены;
*   какие изменения готовы к коммиту;
*   какие файлы Git ещё не отслеживает.

Чтобы вызвать ранее введённую команду, можно использовать стрелку ↑ на клавиатуре.

## Добавление файлов

`git add`

<img width="475" height="47" alt="image" src="https://github.com/user-attachments/assets/8013d72e-9f5d-4484-8dde-834c8c1d10f1" />

Добавляет изменения в индекс (staging area) для последующего коммита.

Например:

`git add файл.txt`

Чтобы добавить все изменённые файлы:

`git add .`

## Создание коммита

`git commit`

<img width="562" height="98" alt="image" src="https://github.com/user-attachments/assets/3c18d740-3410-40db-adb7-32cf68bb7d4e" />

Фиксирует подготовленные изменения и сохраняет их в истории Git.

Обычно используется с сообщением:

`git commit -m "Описание изменений"`

Команда `git commit` берёт изменения, добавленные с помощью `git add`, и сохраняет их как новую версию в истории.

## Просмотр истории

`git log`

<img width="466" height="138" alt="image" src="https://github.com/user-attachments/assets/7e3862f2-846f-41d3-be38-ca68642ca631" />


Показывает историю коммитов:

*   количество сохранений;
*   авторов;
*   даты;
*   сообщения коммитов;
*   идентификаторы коммитов.

Для выхода из просмотра журнала нажмите `q`.

## Переключение между версиями

`git checkout`

<img width="534" height="72" alt="image" src="https://github.com/user-attachments/assets/4d54ab25-66a6-4b36-881b-927a648f5442" />

Позволяет переключаться между версиями файлов или ветками.

Для перехода к определённому коммиту:

`git checkout <идентификатор-коммита>`

Для возврата на основную ветку:

`git checkout main`

В старых репозиториях основная ветка может называться `master`:

`git checkout master`

## Просмотр изменений

`git diff`

<img width="476" height="149" alt="image" src="https://github.com/user-attachments/assets/54ebbac0-daa2-4b9c-a13f-1c82a8b3d9a9" />

Показывает разницу между текущими изменениями и сохранённой версией.

Позволяет увидеть, какие строки были добавлены, удалены или изменены.

# Добавление изображения


> Добавим изображение в файл-инструкцию. В Git не принято добавлять файлы изображений, их хранят на сторонних носителях. Чтобы исключить ненужные файлы из загрузки, есть команда git ignore.  


# Конфликт изменений  


> При работе в двух ветках одновременно может возникнуть ситуация, когда в одной и другой ветке мы по-разному изменили блок текста. Если затем мы попробуем слить эти ветки, Git сообщит о конфликте и предложит выбрать, какие же изменения записать.   


> Поэтому у проекта в репозитории должен быть один ответственный пользователь, наделённый правом проводить слияния и разрешать конфликты.

# MARKDOWN — ОСНОВНЫЕ ЭЛЕМЕНТЫ

Markdown — простой язык разметки текста.

## Жирный текст

Для жирного текста используются две звёздочки:

**жирный текст**

## Курсив

Для курсива используется одна звёздочка:

*курсив*

## Зачёркнутый текст

Для зачёркивания используются две тильды:

~~зачёркнутый текст~~

## Заголовки

Для создания заголовка используется символ `#` в начале строки.

# Заголовок 1

## Заголовок 2

### Заголовок 3

Количество символов `#` определяет уровень заголовка.

## Нумерованные списки

Используются обычные цифры:

1. Первый пункт
2. Второй пункт
3. Третий пункт

## Ненумерованные списки

Используются символы `*`, `-` или `+` в начале строки:

*   Первый пункт
*   Второй пункт
*   Третий пункт

## Вложенные списки

Для создания вложенного списка используется отступ:

*   Первый пункт
    *   Вложенный пункт
    *   Ещё один вложенный пункт
*   Второй пункт

# САМОЕ ВАЖНОЕ

*   `git --version` — проверить версию Git
*   `git init` — создать Git-репозиторий
*   `git status` — посмотреть состояние репозитория
*   `git add` — подготовить изменения к коммиту
*   `git commit` — сохранить изменения в истории
*   `git log` — посмотреть историю коммитов
*   `git checkout` — переключиться между версиями или ветками
*   `git diff` — посмотреть различия между версиями

# ОСНОВНАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ РАБОТЫ

`git init` ↓ Создаём или изменяем файлы ↓ `git status` ↓ `git add .` ↓ `git commit -m "Описание изменений"` ↓ `git log`
